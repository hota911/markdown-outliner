## [0.1.6] - 2026-10-14

### Added

- Tasks and Pomodoro Timer fields (`[🍅:: 1/3]`, `🔁 every day`, `📅 2026-10-15`, `^id`) are shown as badges, with pomodoro sums for items with children and for the items shown.
- Experimental, Obsidian only: the 🍅 button of a task row starts a pomodoro on that task with the Pomodoro Timer plugin, adding a block ID to the task if needed.
- Recurring tasks in the Obsidian Tasks format: completing a task with `🔁 every week` (and other day, week, weekday, month and year rules, also `when done`) adds `✅` with the date and puts its next occurrence above it, with the `📅` due, `⏳` scheduled and `🛫` start dates moved as Tasks does and the `[🍅:: n/m]` pomodoro count reset. Works in the web and desktop versions and without the Tasks plugin; one Undo removes the next occurrence.
- Links to files of the vault or folder, such as `[plan](notes/plan.md)`, in item texts and notes: Obsidian opens the file (⌘/Ctrl-click: in a new tab), and the web version opens a Markdown file in the outliner and other files from the server.
