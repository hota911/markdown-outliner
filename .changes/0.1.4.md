## [0.1.4] - 2026-10-10

### Added

- An agent skill, `skills/markdown-outliner/`, that teaches coding agents such as Claude Code, Codex, Cursor and Gemini CLI the file format: items, nesting, statuses, notes, tags and embeds, the rules that keep a file readable by the outliner, and examples of common edits. Install it with `npx skills add hota911/markdown-outliner` or copy the folder into an agent's skills folder.
- Headings are shown as read-only rows that fold and zoom, and items move across them with Alt+Up/Down and drag and drop.
- The `/` command menu has Collapse and Expand for an item with children: Collapse while its children are shown, Expand while they are hidden. They match English and Japanese words such as `/fold`, `/col`, `/折` and `/展開`, and the focus stays in the item's text.

### Changed

- The header with the file picker, the filter, the search box and the buttons stays at the top of the view while a long file scrolls, together with the zoom bar when an item is zoomed in. Moving between items with the keyboard keeps the focused item below it.
- The bookmarks sidebar scrolls apart from the outline: it stays in place while the outline scrolls, and a list longer than the view scrolls inside the sidebar. On screens 600px wide or narrower, where the bookmarks are above the outline, they take at most 40% of the screen height and scroll inside.

### Fixed

- A collapsed item stays collapsed by itself. Before, an edit also collapsed every other item with the same text, and a change made outside the outliner that added or removed lines above a collapsed item collapsed a different item instead. An item whose own line is changed outside the outliner now expands.
- A long bookmark name wraps inside the bookmarks sidebar instead of spilling over the next bookmark in Obsidian, where every button has a fixed height.
- Large files open and edit much faster. Reading a file took time growing with the square of its length, so on a 2MB file each keystroke took seconds.
