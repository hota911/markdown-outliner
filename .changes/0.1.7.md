## [0.1.7] - 2026-10-19

### Added

- ⌘F (Ctrl+F on Windows and Linux) moves the focus to the search box
- Dragging the text of an item onto another item selects the items between them
- Change the pomodoro estimate of a task with the +🍅 and −🍅 row buttons or the "🍅 Estimate +1/−1" commands of the / menu.
- The "One-line notes" toolbar toggle shows only the first line of each note until it is edited; bookmarks save it with the view
- On macOS, Ctrl+P / Ctrl+N move between items, and in the / and # menus, as Up / Down do
- While filtering, an item that matches shows an "N more" button when the filter hides items under it, such as the done and not started subtasks of an in-progress task; it shows them, dimmed, until "Hide" is pressed or the filter or file changes

### Changed

- The search box filters the outline as you type, without waiting for Enter

### Fixed

- With a filter or a fold, Backspace at the start and Delete at the end of a title merge the item with the nearest item on screen instead of a hidden one, and leave the hidden items in between as they are. An item with children is not merged across hidden items.
- With a status filter, a bullet follows the status of its nearest task, so the bullets under a done task no longer show when filtering for tasks not done
